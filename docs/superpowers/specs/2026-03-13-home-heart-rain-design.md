# 首页爱心雨动画设计

**目标**
在首页“我的清单”标题右侧增加一个粉色爱心按钮，点击后播放全屏爱心雨动画，动画结束后自动恢复首页正常显示。

**设计**
- 爱心按钮放在首页标题区域右侧，使用系统 `heart.fill`，颜色为粉色。
- 点击后显示一个覆盖全屏的动画层，首页内容仍保留在下方，但交互被动画层拦截，防止重复点击或与列表手势冲突。
- 动画采用纯 SwiftUI 实现：大量粉色爱心从屏幕顶部落下，大小、位置、旋转和时间略有随机，形成更有仪式感的 `2~3s` 爱心雨效果。
- 在动画后段增加更密集的爱心覆盖感，形成“铺满屏幕”的视觉印象，随后整体淡出，恢复正常页面。

**边界**
- 动画进行中禁用再次点击爱心按钮。
- 如果此时有展开卡片或删除确认框，优先收起这些临时状态，再开始动画。
- 不改动搜索、删除、编辑和卡片展开的数据逻辑，只在首页增加一个独立动画层。
