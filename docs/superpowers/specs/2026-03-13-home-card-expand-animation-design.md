# 首页卡片展开动画设计

**目标**
在首页卡片上增加点击展开动画：有图片时固定高度展开并展示标题与图片；无图片时只执行一次轻微抖动，不进入展开态。

**设计**
- 首页同一时间只允许一张卡片处于展开态，状态由 `HomeView` 统一管理，避免列表内多个卡片同时展开导致页面混乱。
- `StoredItemRow` 保持为展示组件，但新增展开态参数和点击回调。展开时禁用左右滑动，避免和现有删除/编辑手势冲突。
- 展开后的卡片宽度保持不变，高度变为固定值，接近正方形。展开内容只保留顶部居中的标题和中下部的图片，原本的状态色块、更多图标、剩余天数信息隐藏。
- 没有图片的卡片点击时不展开，只执行一次短促抖动，作为“当前无可展开内容”的反馈。

**数据流**
- `HomeView` 记录 `expandedItemID`。
- 点击卡片时：
  - 有图：在 `nil`、当前卡片 id、其他卡片 id 之间切换展开状态。
  - 无图：触发卡片自己的抖动反馈。
- 左右滑动仅在未展开时可用。

**边界与兼容**
- 保留现有搜索过滤。
- 保留现有左滑编辑、右滑删除、自定义删除弹窗。
- 展开态再次点击同一卡片时收起。
- 切换展开卡片时使用 spring 动画，避免生硬跳变。
